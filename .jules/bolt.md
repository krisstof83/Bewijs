## 2024-06-21 - Batch SQLite inserts
**Learning:** In Node.js `sqlite3`, inserting records one-by-one without a transaction forces a disk fsync for every `db.run()`, acting as a major performance bottleneck. Always batch multiple inserts using `BEGIN TRANSACTION` and `COMMIT` within `db.serialize()` along with `db.prepare()` to ensure performance scaling. When batching SQLite inserts using `db.serialize()`, ensure that synchronous operations (like `fs.readFileSync`) within the transaction block are wrapped in a `try...catch`. Uncaught synchronous errors will prevent subsequent database operations (like `COMMIT`) from being queued, causing transaction leakage and permanently locking the database.
**Action:** When performing multiple database inserts in a loop, always use `db.serialize()` to enforce order, wrap the queries in a transaction (`BEGIN TRANSACTION` and `COMMIT`), and handle errors gracefully to avoid leaked transactions.
