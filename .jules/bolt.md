## 2024-05-31 - SQLite Synchronous Loops Batching Strategy
**Learning:** In Node.js `sqlite3`, inserting records one-by-one without a transaction forces a disk fsync for every `db.run()`, which acts as a major performance bottleneck. Furthermore, when batching inserts via `db.serialize()` with a synchronous loop (e.g., using `fs.readFileSync`), uncaught synchronous exceptions prevent subsequent database operations (like `COMMIT`) from running, permanently leaking the transaction lock.
**Action:** Always batch multiple inserts using `BEGIN TRANSACTION` and `COMMIT` within `db.serialize()`. Combine this with `db.prepare()` and wrap all synchronous block execution (like file reads) inside a `try...catch` block to ensure transactions are committed even if specific file reads fail.
