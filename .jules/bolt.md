## 2025-02-24 - Batching SQLite Inserts and Sync Error Handling
**Learning:** In Node.js `sqlite3`, inserting records one-by-one without a transaction forces a disk fsync for every `db.run()`, acting as a major performance bottleneck. Furthermore, when batching inserts inside `db.serialize()`, synchronous operations (like `fs.readFileSync`) must be wrapped in `try...catch`, because uncaught synchronous errors will prevent subsequent database operations (like `COMMIT`) from queuing, permanently locking the database.
**Action:** Always batch multiple inserts using `BEGIN TRANSACTION` and `COMMIT` within `db.serialize()` along with `db.prepare()`, and wrap synchronous code inside the transaction block with `try...catch` to ensure robust error handling and prevent transaction leakage.
